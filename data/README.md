# Как заполнять каталог

Каталог — наши собственные данные. Собираем вручную, без парсинга сайтов.
Цель к четвергу 26 ноября: 60–100 товаров из 3 магазинов РК.

## Что можно и что нельзя

- Можно: название товара, бренд, категорию, цвет, цену, цифры размерной сетки, ссылку на страницу товара.
- Нельзя: копировать фото товаров, тексты описаний и любые картинки с сайтов магазинов (авторское право).
- Нельзя: запускать парсеры и обходить защиту сайтов.
- Цены пишем на дату сбора, дату указываем в `collected_at`.

Файлы в кодировке UTF-8, разделитель — запятая. Удобно заполнять в Google Таблицах и скачивать как CSV.
Если в ячейке есть запятая (например, в `style_tags`), ячейку берём в кавычки — Google Таблицы делают это сами.

## size_charts/size_charts.csv — размерные сетки

Одна строка — один размер одного бренда в одной категории. Цифры — обхваты **тела** в сантиметрах из таблицы размеров магазина.

| Колонка | Пример | Правило |
|---|---|---|
| store | Lamoda KZ | точно как в stores.csv |
| brand | Bershka | бренд |
| category | tshirt | одно из: tshirt, shirt, hoodie, jacket, trousers, jeans, skirt, dress |
| gender | female | female, male или unisex |
| size_label | M | размер как в магазине: M, 44, 28/32 |
| size_order | 3 | порядковый номер размера от меньшего к большему: XS=1, S=2, M=3… |
| chest_min, chest_max | 88, 92 | обхват груди; для брюк и юбок оставить пустым |
| waist_min, waist_max | 70, 74 | обхват талии |
| hips_min, hips_max | 94, 98 | обхват бёдер; для футболок можно пустым |
| height_min, height_max | 164, 170 | рост, если указан в таблице, иначе пусто |

Если у бренда одна общая таблица буквенных размеров (как у Mango: XXS–4XL по груди, талии и бёдрам),
её строки повторяются для каждой категории, которая продаётся в этих размерах. Вещи с цифровыми
размерами (32, 34, 36…) добавляются только вместе с таблицей именно этих размеров.

Если в таблице магазина одно число вместо диапазона (например, «грудь 90»), пишем его в обе колонки: 90 и 90.
У каждой зоны заполняем либо обе границы, либо ни одной.

## catalog/products.csv — товары

| Колонка | Пример | Правило |
|---|---|---|
| store | Lamoda KZ | как в stores.csv |
| brand | Bershka | для бренда должна быть размерная сетка этой категории и пола |
| title | Футболка оверсайз хлопковая | своими словами, коротко |
| category | tshirt | см. список выше |
| gender | female | female, male или unisex |
| price_kzt | 7990 | цена в тенге, целое число |
| color_name | молочный | цвет словами |
| color_hex | #f3eee3 | цвет в формате #RRGGBB (подобрать пипеткой или на глаз) |
| style_tags | casual,street | один или несколько: casual, office, sport, evening, street |
| season | all | summer, demi, winter или all |
| product_url | https://www.lamoda.kz/p/... | прямая ссылка на товар |
| collected_at | 2026-11-25 | дата сбора |

## Проверка

```bash
cd backend
python -m scripts.import_catalog
```

Скрипт покажет все ошибки с номером строки и не изменит базу, пока ошибки есть.
